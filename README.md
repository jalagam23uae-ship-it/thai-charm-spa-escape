# Thai Charm Spa Escape

Build a polished, responsive website for “Thai Charm Spa” following the attached specification, using React, TypeScript, and Tailwind CSS instead of plain HTML/Bootstrap:
- A welcoming, elegant spa design with light backgrounds, dark text, calm green accents, generous spacing, and rounded imagery
- Sticky navbar with Home, Treatments, Packages, About, Gallery, Contact, and Book Now button
- Hero section with heading “Relax. Restore. Reconnect.” and supporting text
- Treatments menu cards (Traditional Thai Massage, Aromatherapy, Deep Tissue, Foot Reflexology, Hot Stone, Couples Massage) with editable durations, prices, and treatment request actions
- Packages section with three package cards
- About section introducing the spa experience
- Gallery grid with soothing spa photography
- FAQ accordion for common questions
- Booking and Contact section with editable contact details, phone, email, and WhatsApp appointment request link with prefilled message
- Complete footer with business info and navigation links
